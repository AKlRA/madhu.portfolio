# G. Madhusudhana portfolio

A static, light-theme engineering portfolio for G. Madhusudhana, Deputy Manager, Design and Development at Ace Designers Limited.

## Preview

Open `index.html` in a browser. No build step is required.

## Files

- `index.html` - portfolio content, project index, and CV-backed experience
- `styles.css` - light-theme visual system, responsive layouts, and reduced-motion support
- `script.js` - subtle section reveals and current-year footer label
- `assets/` - portrait and manufacturing photography
- `resume.pdf` - CV linked from the header
- `index-single-file.html` - inlined copy for sharing when needed

## GitHub Pages

Keep `index.html` at the repository root and enable Pages from Settings, Pages, Deploy from branch, main, `/ (root)`.

## Theme

The portfolio uses a light theme only. The layout is inspired by the supplied portfolio-motion reference and uses brief project summaries, manufacturing photography, and résumé-backed profile details.
